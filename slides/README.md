# Slides da Apresentação

Este diretório deve conter os slides usados na apresentação do projeto (exigência do
enunciado, `docs/PROJETO.md`, seções 12 e 13).

A apresentação deve cobrir: motivação, modelo de simulação, algoritmo próprio e principais
resultados, defendendo as decisões tomadas e explicando os gráficos. Duração de 10 a 12
minutos. Todos os integrantes devem participar, demonstrando domínio sobre alguma parte do
trabalho.

Formato sugerido: `.pptx` ou PDF exportado.
